# Grokking Deep Learning

This repository contains my code reproduction and notes from the book **Grokking Deep Learning** by Andrew W. Trask.

The repository was created as part of my Deep Learning class assignment. Each notebook contains theoretical explanations, code reproduction, outputs, interpretations, and a chapter summary.

## Chapters

### Chapter 1 - Introducing Deep Learning
Introduces deep learning, its applications, and the tools required to start learning it.

### Chapter 2 - Fundamental Concepts
Explains machine learning, deep learning, supervised learning, unsupervised learning, and different learning approaches.

### Chapter 3 - Forward Propagation
Explains how neural networks combine inputs and weights to create predictions.

### Chapter 4 - Gradient Descent
Explains error calculation and how neural networks learn by updating weights.

### Chapter 5 - Learning Multiple Weights
Extends gradient descent to networks with multiple inputs, weights, and outputs.

### Chapter 6 - Backpropagation
Introduces hidden layers and explains how error is propagated backward through a deep neural network.

### Chapter 7 - Visualizing Neural Networks
Develops an intuitive understanding of neural network layers, connections, weights, and information flow.

### Chapter 8 - Regularization and Batching
Explains overfitting, dropout, regularization, and batch-based training.

### Chapter 9 - Activation Functions
Introduces nonlinear activation functions and probability-based predictions.

### Chapter 10 - Convolutional Neural Networks
Explains convolution, filters, feature maps, edges, and visual pattern learning.

### Chapter 11 - Word Embeddings
Explains how neural networks represent words as vectors and learn semantic relationships.

### Chapter 12 - Recurrent Neural Networks
Introduces recurrent networks, hidden states, and learning from sequence data.

### Chapter 13 - Automatic Optimization
Introduces reusable neural network layers, parameters, gradients, and optimizers.

### Chapter 14 - LSTM
Explains vanishing and exploding gradients and introduces Long Short-Term Memory networks.

### Chapter 15 - Federated Learning
Introduces distributed training where clients keep their data locally and share model updates.
