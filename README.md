# Grokking Deep Learning

This repository contains my code reproduction and notes from the book **Grokking Deep Learning** by Andrew W. Trask.

The purpose of this repository is to understand deep learning concepts by reproducing the code from the book and writing short theoretical explanations for each chapter.

## Tools
- Python
- Google Colab / Jupyter Notebook
- NumPy
- Matplotlib

## Reference
Grokking Deep Learning - Andrew W. Trask, Manning Publications
